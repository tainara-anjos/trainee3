Tarefa 6 – 

Esta aplicação é uma API REST simples desenvolvida em Node.js, utilizando Fastify e TypeScript.

O objetivo da atividade é realizar a migração de uma API construída em JavaScript para TypeScript, aplicando tipagem e boas práticas, onde foi acrecentado mais alguns items .

 Conceitos aplicados

- API REST
- CRUD (Create, Read, Update, Delete)
- Tipagem com TypeScript
- Fastify
- Uso de rotas HTTP (GET, POST, PUT, DELETE)
- API Stateless
- Organização de projeto Node.js
- Versionamento com Git e GitHub


Tecnologias utilizadas

Node.js
Fastify
TypeScript
ts-node
npm

Dentro da pasta `tarefa-6`, execute:

bash
npm install
para executara a aplicação 

npm run dev
http://localhost:3000/items
